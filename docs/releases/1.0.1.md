# Family Tree 1.0.1

Fixed cropped wolf portraits in exported family trees. PNG exports now show each wolf's complete head, including its ears and muzzle, using its coat texture.

The family layout and connections are unchanged. Existing pet history is unaffected. This patch supports the same four targets as 1.0.0: Fabric 1.21.1, Fabric 26.1.1, Fabric 26.2, and NeoForge 26.2.

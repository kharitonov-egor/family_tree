# Family Tree 1.0.0

- Existing tamed pets now enter the tracker when their chunks load. The browser's **Find existing pets** button scans pets that are already loaded.
- A first-use chat hint shows your configured key for opening Family Tree.
- Select a pet and click **Locate pet** to get its current or last known location in chat.
- **Export family tree** saves the visible tree as a PNG in `screenshots/familytree/`, independent of screen zoom and pan. Exports include names, generations, and living or deceased status, with cat and wolf portraits. Player names and coordinates are excluded.
- Added Fabric support for Minecraft 1.21.1 and NeoForge support for Minecraft 26.2.
- Fixed a Minecraft 26.2 crash when rendering cat and wolf portraits in the browser or tree.
- Commands, the linking stick, and screen actions now share ownership checks. Public viewing does not grant permission to locate, rename, link, or change the age of another player's pet. Public snapshots omit other players' pet coordinates.
- The linking stick checks ownership again when a player confirms a link.
- Automatic discovery preserves parents and inherited ownership when a newborn enters the world before its breeding event finishes.
- The browser distinguishes an empty tracker from a search with no matches, preserves searches when returning, and wraps controls on smaller screens. Tree cards keep generation and death details visible at a wider range of zoom levels.

| 26.1.1 | Fabric | 25 or newer | Matching Fabric API |

| 26.2 | NeoForge 26.2.0.88 or newer within 26.2 | 25 or newer | None |

Choose the file for your exact Minecraft version and loader. Install Family Tree 1.0.0 on the server and clients. Tracking runs on the server, and the client installation adds the screens. NeoForge builds do not need Fabric API.

## Existing worlds

Pet history, lineage, death records, and custom names remain. Version 1.0.0 does not rename persisted fields or add required save fields. Older records still load through the tolerant save reader.

Update both sides together because 1.0.0 uses new screen packet identifiers. A mismatched Fabric client and server cannot open the screen. The 1.21.1 build is for 1.21.1 worlds, not for downgrading a newer Minecraft world.

Discovery cannot recover parents or birth dates from before the mod recorded them. Newly imported pets use the discovery day until you correct their age. Use the linking stick for known parents. Unloaded pets show a last known location, which may be out of date.

Downgrading Family Tree to a release before 0.3.3 drops custom tree names when it next saves. Original names and lineage remain.

# Family Tree 1.1.0

Add known parents without commands. Select a pet in the tree, choose Add parents, search for both parents, and confirm. Clear recorded parents through a confirmation screen. Horse and donkey parents can link to a mule.

The browser has Getting started and Refresh. The tree also has Refresh and Open folder after export. Export reports the actual PNG filename. The selected browser filter is visible.

## Supported builds

Fabric supports Minecraft 1.21.1, 26.1.1, 26.1.2, 26.2, and 26.3. It requires Fabric Loader 0.19.3 or newer and the matching Fabric API. NeoForge supports 1.21.1 with 21.1.252, 26.2 with 26.2.0.88, and 26.3 with 26.3.0.37-beta. The NeoForge 26.3 release is beta because its loader is beta. Minecraft 1.21.1 uses Java 21; the 26.x builds use Java 25.

## Reliability

- Family snapshots use pages below 256 KiB. The browser shows a completed snapshot and rejects incomplete replies. Tests cover a 10,000-pet snapshot with Unicode names. Snapshots above 100,000 visible records fail with a message rather than silently omitting pets.
- Commands and network requests share cooldowns for loaded-pet scans. Open, rename, locate, and parent-edit requests also have cooldowns.
- Generation calculation uses an explicit stack and passes a 10,000-generation test.
- Unreadable and duplicate save entries remain in the next save. Unsupported future save formats disable edits and preserve the original data. Check the server log for recovery details.
- Legacy import runs once for a new store and copies the old file to a migration backup. Empty modern stores do not import old history again.
- Name-based edits reject ambiguous matches. Use one of the UUIDs printed in chat. Locate still reports all permitted name matches and also accepts an exact UUID.
- Operator pruning writes a JSON backup under the world's `familytree-backups/` directory. A failed backup cancels deletion.
- Jars use exact Minecraft version predicates and include the MIT license, icon, and source links. Linking sessions and portrait caches clear on disconnect.

## Upgrade

Update the server and clients together. This release changes snapshot, open-request, discovery, and NeoForge protocol identifiers. Existing saved record field names stay unchanged.

Back up the world before upgrading. Older mod releases can drop fields they do not understand when saving, and older releases do not protect future formats. Minecraft world downgrades remain unsupported.

A focused tree displays up to six generations in either direction. Use a species view for all its families. Screens refresh when requested rather than updating automatically while open. Revival mods, altered pet models, and modded species still need separate compatibility testing.

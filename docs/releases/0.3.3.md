# Family Tree 0.3.3

- Select a pet and click **Rename** to give it a name just for Family Tree. Its name in the world stays unchanged. **Use original** clears the custom name.
- Owners and server operators can rename their tracked pets, including unloaded pets and deceased records. Commands accept original names and custom tree names.
- **Fit tree** brings the visible tree into view. **Center pet** centers the selected pet at a readable zoom.
- **Hide branch**, **Show branch**, and **Show all** let you collapse and restore descendants. Shared descendants hide with the selected branch.
- Cards show compact portraits and names when zoomed out. Double-click a pet to open its tree. Back or Escape restores the previous view.
- Manual pairing and the linking stick reject ancestry loops. The stick checks again at confirmation in case another player has edited the tree.
- Card borders, connecting lines, and click targets now use the same zoom dimensions.

Install the matching jar for Minecraft 26.1.1 or 26.2, with Fabric API and Java 25. The server and clients should use the same Family Tree version.

Existing saves keep their pet history. Custom tree names use a new optional save field. Older mod versions drop those custom names when saving after a downgrade; original names and lineage remain.

# Validation for 1.1.0

The final local build passed with 39 shared JUnit tests on each of eight targets, 312 test executions. These are the same shared cases compiled against each Minecraft and loader pair.

| Minecraft | Loader | Build and unit tests | Dedicated server | Client and network |
| --- | --- | --- | --- | --- |
| 1.21.1 | Fabric | Pass | Pass | Pass |
| 26.1.1 | Fabric | Pass | Pass | Pass |
| 26.1.2 | Fabric | Pass | Pass | Pass |
| 26.2 | Fabric | Pass | Pass | Pass |
| 26.3 | Fabric | Pass | Pass | Pass with Vulkan |
| 1.21.1 | NeoForge | Pass | Pass | Pass |
| 26.2 | NeoForge | Pass | Pass | Pass |
| 26.3 | NeoForge beta | Pass | Pass | Pass with Vulkan |

Server runs check discovery, the breeding mixin, ownership, renaming, and death records in disposable worlds. Most worlds contain history from prior runs; this is a retained-history check rather than an immutable previous-release fixture. The unit suite also checks future and malformed save formats, rejected and duplicate record preservation, deep ancestry, permission changes, and complete byte-bounded snapshot encoding and decoding for 10,000 records.

Client runs check actual network snapshot and discovery replies, the browser, tree portraits, PNG export, Getting started, the parent picker, and a confirmed parent edit saved by the server. Fabric 26.3 also passed at GUI scale 4. Other capture runs used scale 2.

The real gameplay run on Fabric 26.2 passed vanilla feeding, normal AI breeding, actual parent recording, a real damage and death event, a network snapshot of that family, and PNG export. The scene is automated. The browser and parent-picker example screenshots use staged records.

Minecraft 26.3 crashed before entering the world with this laptop's Intel OpenGL driver. Forcing its Vulkan backend allowed both loader client runs to pass. No system graphics settings changed. Companion pet mods and custom resource-pack models have not been verified by these checks.

Build and runtime commands are in [testing.md](../testing.md). Local logs live under ignored `build/implementation/`. The release manifest records the source commit, exact targets, dependency IDs, Java versions, and SHA-512 hashes. GitHub CI runs the build and unit suite on Linux; it does not run the graphical checks.
